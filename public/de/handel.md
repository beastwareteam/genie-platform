**Sechs Bausteine** für Handelsangaben: Preis, Produkt, Warenkorb, Gutschein, Bewertung,
Merkliste.

Damit lassen sich Produktübersichten, Warenkorb-Ansichten und Bewertungsdarstellungen
zusammenstellen — als Teil einer größeren Fläche oder für sich allein.

## Was da ist

| Baustein | Zeigt |
| --- | --- |
| Produktkarte | ein Produkt mit Bild, Bezeichnung und Preis |
| Preisangabe | einen Preis, gegebenenfalls mit Streichpreis |
| Warenkorb | Positionen, Steuer, Versand und Endsumme |
| Bewertungsübersicht | Durchschnitt und Verteilung von Bewertungen |
| Gutschein-Feld | einen Gutschein-Code |
| Merkliste | vorgemerkte Produkte |

## Was diese Bausteine sind — und was nicht

**Sie stellen dar.** Sie rechnen keine Bestellung ab, sie sprechen mit keinem Zahlungsdienst,
und sie führen kein Warenwirtschaftssystem. Ein Warenkorb zeigt eine Summe; er kassiert sie
nicht.

Das ist keine Einschränkung, die sich beiläufig beheben ließe — Zahlungsabwicklung ist ein
eigenes Feld mit eigenen Pflichten. Wenn Sie so etwas brauchen, brauchen Sie eine Anbindung an
ein System, das es kann.

**Wofür sie taugen:** eine Übersicht über eigene Produkte, ein Angebotsvergleich, eine
Darstellung von Daten, die woanders herkommen — überall dort, wo etwas mit Preisen zu tun hat,
aber nichts verkauft wird.

## Was hier ehrlicherweise offen ist

- Gutschein-Feld und Merkliste sind noch Gerüste: sie zeigen an, bringen aber noch keine
  ausgebaute Bedienung mit. Im Verzeichnis sind sie als solche gekennzeichnet.
- Es gibt keine Währungsumrechnung und keine Steuerlogik. Angezeigt wird, was hinterlegt ist.
- Eine Anbindung an Verkaufsplattformen oder Warenwirtschaft besteht nicht.
