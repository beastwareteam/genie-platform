# Beschreiben Sie es. Es entsteht.

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="../bilder/kopf/start.png">
  <img src="../bilder/kopf/start_hell.png" alt="Bannerbild: die Überschrift „Beschreiben Sie es. Es entsteht.“ neben einem gebauten Formular mit den Feldern Name, Abteilung und Gültig ab.">
</picture>

Genie Platform ist eine Arbeitsumgebung, die sich beim Benutzen selbst zusammenbaut. Sie
sagen in einem Satz, was Sie brauchen — eine Tabelle Ihrer offenen Rechnungen, ein Diagramm
der Ausgaben je Monat, ein Browserfenster mit zwei Reitern — und daraus entsteht eine
bedienbare Fläche. Keine Auswahl aus einem Baukasten, kein leeres Formular, das erst
ausgefüllt werden will.

**Das Wichtigste läuft dabei auf Ihrem Rechner.** Sprachmodelle, Sprachausgabe,
Texterkennung, Datenbank — alles davon hat einen örtlichen Weg. Dienste im Netz sind eine
Wahl, kein Zwang.

*Aus einem Satz entstanden. Sortieren über die Spaltenköpfe, filtern über das Suchfeld,
ausgeben als CSV — nichts davon musste eigens angefordert werden.*

## Was das im Alltag heißt

| | |
| --- | --- |
| **Sie beschreiben, statt zu bauen** | Ein Satz in Alltagssprache genügt. Was Sie nicht sagen, wird sinnvoll gefüllt — und ist danach änderbar. |
| **Was Sie einstellen, bleibt** | Spaltenbreiten, Trenner, Reiter-Reihenfolge überleben den Neubau einer Fläche. |
| **Das Aussehen ist eine Einstellung** | Farben, Abstände und Rundungen kommen aus einem Theme und lassen sich im Betrieb wechseln. |
| **Selbsttätige Arbeit hat einen Not-Aus** | Die Plattform kann sich selbst erweitern — ab Werk **ausgeschaltet**, <!-- fakt: not_aus_ab_werk --> und jederzeit sofort anzuhalten. |

## Loslegen

!!! warning "Der Quelltext im Verzeichnis ist noch nicht auf diesem Stand"

    Diese Seiten beschreiben die Plattform, wie sie gerade entwickelt wird. Der Quelltext
    wird davon getrennt veröffentlicht und hinkt derzeit hinterher — was Sie mit den
    Befehlen unten bekommen, ist ein älterer Stand.

```bash
git clone https://github.com/beastwareteam/genie-platform.git
cd genie-platform
pip install -e .
python -m genie.main
```

Danach genügt ein Satz im Chat-Fenster. Wenn etwas nicht kommt, sagt `/status`, woran es
hängt; `/wiki` erklärt die Bedienung ausführlich.

## Was hier ehrlicherweise offen ist

- **Die Plattform ist in Entwicklung.** Sie läuft, aber sie ist kein fertiges Erzeugnis mit
  Zusicherungen.
- **Für das Gesamtwerk ist noch keine Lizenz gesetzt** — siehe [Lizenzen und
  Herkunft](lizenzen.md). Bis dahin gilt: alle Rechte vorbehalten.
- **Barrierefreiheit ist angestrebt, nicht geprüft.** Was fehlt, steht auf der Seite
  [Barrierefreiheit](barrierefreiheit.md) namentlich.
- **Der öffentliche Quelltext hinkt hinterher.** Die Seiten hier sind aktuell, das
  Verzeichnis noch nicht — beides wird getrennt veröffentlicht.
- Getestet wird auf Windows. Andere Systeme sind vorgesehen, aber nicht durchgeprüft.
